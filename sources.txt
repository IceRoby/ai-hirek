# FORMÁTUM SZABÁLYOK:
#   rss    | Forrás neve | https://feed-url.com/rss
#   domain | Forrás neve | example.com
#
# MEGJEGYZÉS SZABÁLYOK:
#   # karakterrel kezdődő sor = megjegyzés, nem fut le
#   #rss   | Forrás neve | url  → KIKAPCSOLT feed (tartalék)
#   #domain| Forrás neve | url  → KIKAPCSOLT domain
#
# HOGYAN AKTIVÁLJ EGY TARTALÉK FEEDET:
#   1. Keresd meg a #rss kezdetű sort
#   2. Töröld a # karaktert az elejéről
#   3. Mentsd el → következő futástól aktív
#
# HOGYAN KAPCSOLJ KI EGY FEEDET:
#   1. Tedd # karaktert a sor elejére
#   2. Mentsd el → következő futástól inaktív
#
# HOGYAN ADJ HOZZÁ ÚJ FEEDET:
#   Új sort írsz a megfelelő szekcióba:
#   rss | Saját Forrás Neve | https://example.com/feed.rss
#
# STATISZTIKA:
#   A history.txt fájlban látod melyik feed hány cikket hozott.
#   Ha egy feed 7+ futáson át 0 cikket hoz → érdemes kikapcsolni
#   és egy tartalékkal felváltani.
