# ================================================================
# WORDPRESS OLDALAK KONFIGURÁCIÓS FÁJL (wordpress.txt)
# ================================================================
#
# Minden WordPress oldal beállításai itt vannak.
# Formátum: wp | kulcs | érték
#
# OLDAL AZONOSÍTÓK: wp1, wp2, wp3, wp4, wp5...
# Minden oldalhoz ugyanazok a kulcsok tartoznak, csak a szám változik.
#
# KÖTELEZŐ MEZŐK minden oldalhoz:
#   wp{N}_url    → az oldal URL-je (https://... trailing slash nélkül)
#   wp{N}_user   → WordPress felhasználónév
#
# OPCIONÁLIS MEZŐK:
#   wp{N}_tipus        → altalanos / tema:kulcs / kategoriak:Kat1,Kat2
#   wp{N}_post_status  → publish / draft / pending
#   wp{N}_post_mode    → summary / individual / append
#   wp{N}_kategoria    → WP kategória neve (létrehozza ha nincs)
#   wp{N}_szerzo       → szerző neve (pontosan ahogy WP-ben van)
#   wp{N}_kep_url      → fix kép URL (ha nincs, Pexels/Unsplash keres)
#   wp{N}_kep_kulcsszo → kép keresési kulcsszó Pexels/Unsplash-en
#
# OLDAL TÍPUSOK (wp{N}_tipus):
#   altalanos          → minden aktív téma minden híre felkerül
#   tema:ai            → csak AI témájú hírek
#   tema:coaching      → csak coaching témájú hírek
#   kategoriak:Kat1,Kat2 → csak ezekből a kategóriákból kerülnek fel hírek
#                          (a categories.txt-ben definiált nevek)
#
# POST MÓD (wp{N}_post_mode):
#   summary    → 1 összefoglaló post (ITE.hu stílus: 1 kép, hírek egymás után)
#   individual → minden hír külön post (jobb SEO-hoz)
#   append     → hozzáfűz a napi posthoz (óránkénti futáshoz ideális,
#                az új hírek mindig a tetejére kerülnek)
#
# APP PASSWORDÖK → GitHub Secrets-ben (WP1_APP_PASSWORD, WP2_APP_PASSWORD...)
# KÉP API KULCSOK → GitHub Secrets-ben (PEXELS_API_KEY, UNSPLASH_API_KEY)
#
# RÉSZLETES BEÁLLÍTÁSI ÚTMUTATÓ: SETUP_WP.md
# ================================================================
